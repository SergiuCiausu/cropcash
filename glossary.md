# Glossary

Terms used in `subventii-surse.md` and `subventii-plan.md`. Romanian names are kept where that's what you'll see on the sites.

These are plain-language explanations for working on the project, not legal or funding advice.

---

## Who runs what: Romanian institutions

| Term | Full name | What it does |
|---|---|---|
| **MADR** | Ministerul Agriculturii și Dezvoltării Rurale | The agriculture ministry. Sets policy and publishes national plans, orders and calendars. |
| **APIA** | Agenția de Plăți și Intervenție pentru Agricultură | Pays farmers their yearly subsidies, mostly per hectare or per animal. |
| **AFIR** | Agenția pentru Finanțarea Investițiilor Rurale | Funds rural investment projects, such as modernizing a farm. Farmers apply during set sessions. |
| **OJFIR / CRFIR** | – | AFIR's county offices and regional centres. |
| **MIPE** | Ministerul Investițiilor și Proiectelor Europene | The ministry coordinating EU funds. Its site is `mfe.gov.ro`, from the older name Ministerul Fondurilor Europene. |
| **ADR** | Agenție pentru Dezvoltare Regională | Runs EU regional funding. Romania has eight, including Sud-Muntenia, Centru and Nord-Est. |
| **DAJ** | Direcția Agricolă Județeană | The ministry's county agricultural offices. Good for local notices and information sessions. |
| **ANSVSA** | Autoritatea Națională Sanitară Veterinară și pentru Siguranța Alimentelor | The veterinary and food safety authority. |
| **DSVSA** | Direcția Sanitar-Veterinară și pentru Siguranța Alimentelor | ANSVSA's county offices. |
| **ONVPV** | Oficiul Național al Viei și Produselor Vitivinicole | The national vine and wine office. Keeps the vineyard register and handles planting authorizations. |
| **FGCR** | Fondul de Garantare a Creditului Rural | Guarantees loans for farmers, so banks will lend more easily. It lends no money itself. |
| **FNGCIMM** | Fondul Național de Garantare a Creditelor pentru IMM | The same idea for small and medium businesses. |
| **GAL** | Grup de Acțiune Locală | A local partnership of councils, businesses and community groups that funds local projects. Each publishes calls on its own site. |
| **FNGAL** | Federația Națională a Grupurilor de Acțiune Locală | The national federation of GALs. |
| **RRN** | Rețeaua Rurală Națională | The national rural network. Shares information about the farm policy. |

## EU funding: the main pots

| Term | Meaning |
|---|---|
| **PAC / CAP** | Politica Agricolă Comună, the Common Agricultural Policy. The EU's farm policy and the main source of farm money. |
| **Pillar I** | The CAP's yearly payments to farmers. In Romania these go through APIA. |
| **Pillar II** | The CAP's rural development money, mostly for projects and investments. In Romania this largely goes through AFIR. |
| **FEGA / EAGF** | The EU fund behind Pillar I. |
| **FEADR / EAFRD** | The EU fund behind Pillar II. |
| **PS PAC / PNS** | Planul Strategic PAC 2023-2027, also called Planul Național Strategic. Romania's plan for spending CAP money. |
| **PNDR** | Programul Național de Dezvoltare Rurală. The older rural development programme, before PS PAC. |
| **Cohesion policy** | EU money that reduces gaps between regions. It's separate from the CAP. MIPE's calendars mostly cover this. |
| **PNRR** | Planul Național de Redresare și Reziliență. Romania's recovery and resilience plan, funded separately by the EU. |
| **PDD** | Programul Dezvoltare Durabilă. Environment, climate and energy. |
| **PEO** | Programul Educație și Ocupare. Education and employment. |
| **PIDS** | Programul Incluziune și Demnitate Socială. Social inclusion. |
| **PoCIDIF** | Programul Creștere Inteligentă, Digitalizare și Instrumente Financiare. Innovation, digitalization and financial tools. |
| **PR SM** | Programul Regional Sud-Muntenia. That region's EU regional programme. Each region has its own. |
| **PTJ** | Programul Tranziție Justă. Supports areas moving away from high-carbon industries. |
| **PAP** | Programul pentru Acvacultură și Pescuit. Fisheries and aquaculture funding. |
| **LEADER** | The EU's bottom-up rural approach. Local groups (GALs) decide what to fund in their area. |
| **SDL** | Strategie de Dezvoltare Locală. A GAL's local plan for spending its LEADER money. |
| **Horizon Europe** (Orizont Europa) | The EU's research and innovation programme. Calls usually need several partners. |
| **LIFE** | The EU's environment and climate programme. |
| **EIC** | European Innovation Council. Part of Horizon Europe, focused on innovative companies. |

## Farm funding terms

| Term | Meaning |
|---|---|
| **Cerere Unică de Plată** | The single yearly application a farmer files with APIA for subsidies. |
| **AGI Online** | APIA's online system for submitting that application. |
| **LPIS** | Land Parcel Identification System. The register and map of farm parcels, used to check claims. |
| **Eco-schemes** (eco-scheme) | Extra CAP payments for environmentally friendly farming practices. |
| **Intervention** (intervenție) | One funding measure inside PS PAC. Each has its own code. |
| **DR-xx** | Rural development intervention codes. For example: DR-14 small farms, DR-15 fruit growing, DR-16 vegetables and potatoes, DR-17 hops and table grapes, DR-20 livestock, DR-30 young farmers. |
| **CIS-YF** | Extra income support for young farmers. |
| **ISV-xx** | Wine sector interventions, such as vineyard investments. |
| **Ajutor de stat** (state aid) | Support from national public money, which EU rules limit. |
| **De minimis** | Small aid amounts that fall below the state aid notification threshold. |
| **Renta viageră** | A lifelong payment linked to selling or leasing out farmland. |
| **Forță majoră** | An exceptional event, such as drought, that a farmer must report within a deadline. |
| **Nerambursabil** | Non-repayable: a grant, not a loan. |
| **Cofinanțare** (co-financing) | The share of a project's cost the applicant pays. |
| **Ghidul solicitantului** | The applicant's guide. The main document for a funding session: who qualifies, what's covered and how to apply. |
| **Sesiune** | A time window for submitting applications. |
| **Apel** (call) | A published funding opportunity. |
| **MySMIS** | The online system for applying for and managing many EU-funded projects outside the CAP. |
| **OMADR / OM** | An order from the agriculture minister. |
| **HG** | Hotărâre de Guvern, a government decision. |
| **OUG** | Ordonanță de Urgență a Guvernului, a government emergency ordinance. |
| **Monitorul Oficial** | The official gazette, where laws and orders are published. |
| **Rectificat** | Corrected. In a file name, it usually signals a newer version of a document. |

## EU funding portal and API

| Term | Meaning |
|---|---|
| **Funding & Tenders Portal** | The European Commission's website listing funding calls and tenders that it manages directly, such as Horizon Europe and LIFE. Most money for Romanian farmers isn't listed here, because the CAP is run nationally. |
| **Grant vs tender** | A grant funds your project. A tender is a contract to sell goods or services to a public body. |
| **Tenders API** | Our shorthand for the portal's search service, which gives call data in a structured form instead of a web page. It covers grants as well as tenders. |
| **SEDIA** | Single Electronic Data Interchange Area, the EU system behind the portal. Also the public key value used in API requests. |
| **Topic** | A specific subject inside a Horizon call, with its own ID, such as `HORIZON-CL6-2027-03-GOVERNANCE-04`. |
| **Forthcoming / Open / Closed** | A call that's announced but not yet accepting applications, accepting them, or finished. |
| **Consortium** | A group of organizations applying together. |
| **SA case** | A state aid case number in the EU competition register. |
| **TAM** | Transparency Award Module. A public EU register of state aid awards. |

## How the monitor works

### Web requests

| Term | Meaning |
|---|---|
| **HTTP** | The way a program asks a website for something. |
| **GET** | "Send me this file or page." |
| **HEAD** | "Tell me about this file, without sending it." Much cheaper than GET. |
| **Headers** | Short information sent along with a response, such as type, size and date. |
| **Status code** | A number summarizing the response. `200` OK, `301/302` moved, `304` unchanged, `403` refused, `404` not found, `5xx` server error. |
| **ETag** | A fingerprint the server gives a file. A new ETag means a new version. |
| **Last-Modified** | The date the server says a file last changed. Not always reliable, and not the publication date. |
| **Content-Length** | File size in bytes. |
| **Validators** | The common name for `ETag` and `Last-Modified`, the headers used to check for changes. |
| **Conditional request** | A GET that says "send it only if it changed", using `If-None-Match` or `If-Modified-Since`. |
| **`304 Not Modified`** | The reply when nothing changed. No file is sent, which is the main saving. |
| **Redirect** | The server pointing you to a different URL. |
| **User-Agent** | The name a program gives itself to a website, ideally with a contact address. |
| **TLS / HTTPS** | The encryption and certificate check protecting a connection. |
| **Certificate chain** | The links proving a site's identity: site certificate, then intermediate, then a root everyone trusts. |
| **Intermediate certificate** | The middle link. Some government servers forget to send it, so Node rejects them until we supply it. |

### Polite crawling

| Term | Meaning |
|---|---|
| **Crawling / scraping** | Reading websites automatically / pulling specific data out of them. |
| **robots.txt** | A file where a site says what automated programs may read. |
| **Crawl-Delay** | A `robots.txt` rule asking for a wait between requests, in seconds. |
| **Rate limit** | A cap on how fast we send requests. |
| **Retry with backoff** | Trying again after a failure and waiting longer each time. |
| **Timeout** | How long to wait before giving up on a request. |
| **CAPTCHA** | A test to stop bots. We never try to get past one. |

### Data and detection

| Term | Meaning |
|---|---|
| **API** | A way for programs to ask a service for data directly, usually in a structured format. |
| **API key** | A code identifying who's calling an API. |
| **JSON** | A common structured data format. |
| **HTML** | The code a web page is written in. |
| **DOM selector** | An address for part of a page, such as "the links inside the main section". |
| **Parser** | Code that reads a format and turns it into usable data. |
| **Hash / SHA-256** | A short fingerprint computed from content. Same content, same hash. |
| **Checksum** | A hash used to check whether data changed. |
| **Normalization** | Cleaning text before comparing it, such as fixing spaces and Romanian letters. |
| **ș/ş and ț/ţ** | Correct comma letters vs older cedilla letters. They look alike but count as different characters, so we convert them. |
| **Encoding** | How text is stored as bytes. The wrong one garbles diacritics. |
| **Diff** | A line-by-line view of what changed between two versions. |
| **Soft 404** | An error page sent with a success code, so it looks like normal content. |
| **OCR** | Reading text from a scanned image. |
| **Sitemap** | A file listing a site's pages, sometimes with change dates. |
| **RSS / Atom feed** | A machine-readable list of a site's latest posts. |
| **Supabase** | A hosted service built on the Postgres database. Our data lives here. |
| **Postgres** | The database system behind Supabase. |
| **Supabase Storage** | Supabase's file storage. Holds our saved page text and diffs. |
| **Bucket** | A folder-like container in Storage. Ours is private. |
| **Secret key / public key** | Supabase's two kinds of key. The secret key has full access and must stay private. The public key is safe to expose, and here it can reach nothing. |
| **Row Level Security (RLS)** | A database rule system deciding who can see which rows. We turn it on and allow nobody except the secret key. |
| **Migration** | A file of database changes, kept with the code so the schema can be rebuilt. |
| **Cron / Task Scheduler** | Tools that run a program on a schedule, on Linux and Windows respectively. |

### Terms specific to this project

| Term | Meaning |
|---|---|
| **Source** | One monitored URL. |
| **`index`** | A source that lists other documents. We watch it for new links. |
| **`pagina`** | A page whose content we watch. |
| **`pdf`** | A document we watch. |
| **Discovery** | Finding new documents through links on index pages. |
| **Baseline** | The state from the first run, which later runs compare against. Not reported as new. |
| **Snapshot** | A saved version of a source, stored only when it really changed. |
| **Cascade** | The ordered checks, cheapest first, stopping as soon as one gives an answer. |
| **Noise** | Page changes that mean nothing, such as a date or visitor counter. |
| **Change event** | The record Plan A creates for a real change, which Plan B reads. |
| **Opportunity** | One structured funding entry: what it is, who qualifies and the deadline. |
| **`stable_key`** | The ID that lets us recognize the same opportunity across runs. |
| **Relevance label** | Direct, conditional, partnership or not relevant for farmers. |
| **Digest** | The farmer-focused summary at the top of the daily report. |

## Subsidy calculation

| Term | What it means |
|---|---|
| **BISS** | Basic Income Support for Sustainability. The main payment per eligible hectare. |
| **CRISS** | Complementary Redistributive Income Support. An extra payment per hectare that favours smaller farms. |
| **CIS-YF** | Complementary Income Support for Young Farmers. |
| **Eco-scheme** | A payment for farming practices that help the climate or environment. |
| **Coupled support** | A payment tied to producing a specific crop or keeping specific animals. |
| **PD-xx, DR-xx** | Intervention codes in Romania's CAP Strategic Plan. PD codes are direct payments, DR codes are rural development. |
| **Cuantum** | The amount paid per unit, such as euro per hectare. |
| **Advance payment** | The part of a payment made first, such as 70% in the 2025 campaign. The rest follows later. |
| **UVM** | Unitate vită mare, a livestock unit used to compare different animals. |
| **Campaign** | The year a farmer applies for. Payments for it usually arrive from that autumn into the next year. |
| **Bani** | One hundredth of a leu. The app stores all money in bani, so rounding stays exact. |
